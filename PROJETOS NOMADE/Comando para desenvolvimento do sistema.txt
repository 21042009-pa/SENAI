Desenvolva um sistema web completo chamado **NÔMADE**, focado em **gestão inteligente de estoque e desempenho de vendas de tênis** para equipes comerciais. O projeto deve transmitir uma identidade moderna, tecnológica, minimalista e profissional.

Utilize como base a documentação enviada e a logo anexada da marca NÔMADE.

IDENTIDADE VISUAL:

* Utilizar predominantemente as cores:

  * Laranja (#FF6B00 ou similar) como cor de destaque
  * Preto (#0F0F0F)
  * Cinza escuro e cinza claro
* Visual moderno inspirado em:

  * SAP
  * Protheus
  * sistemas SaaS modernos
* Interface minimalista, limpa e intuitiva
* Estilo premium streetwear/tech
* Utilizar a logo da NÔMADE como elemento principal da marca
* Design responsivo
* Dark mode elegante

OBJETIVO DO SISTEMA:
Criar uma plataforma de gerenciamento de estoque para uma equipe que vende tênis, permitindo:

* controle de entradas e saídas
* monitoramento em tempo real
* análise de desempenho
* controle de usuários por hierarquia
* relatórios inteligentes
* dashboards modernos

FUNCIONALIDADES PRINCIPAIS:

1. AUTENTICAÇÃO E USUÁRIOS
   Criar sistema de login seguro com:

* Gerente
* Analista
* Operador
* Auxiliar

Cada perfil deve possuir permissões diferentes:

* Gerente: acesso total
* Analista: análise, comentários e tabelas
* Operador: acesso ao estoque e comentários
* Auxiliar: somente estoque

2. DASHBOARD PRINCIPAL
   Criar dashboard moderno contendo:

* gráficos de estoque
* comparativo de vendas
* produtos com baixa quantidade
* movimentações recentes
* alertas inteligentes
* KPIs
* cards com métricas
* visualização clara e moderna

3. SISTEMA DE ESTOQUE
   Funcionalidades:

* cadastro de produtos
* nome
* código
* fornecedor
* lote
* validade
* rastreamento
* descrição
* modelo
* cor
* quantidade

Permitir:

* entrada de mercadorias
* saída de mercadorias
* atualização em tempo real
* notificações automáticas
* filtros inteligentes
* busca rápida

4. RELATÓRIOS E ANALYTICS
   Criar:

* tabelas comparativas
* gráficos modernos
* relatórios exportáveis
* integração futura com Excel e Power BI
* métricas de vendas
* métricas de estoque
* desempenho da equipe

5. EXPERIÊNCIA DO USUÁRIO
   O sistema deve:

* ser extremamente intuitivo
* rápido
* elegante
* minimalista
* profissional
* fácil de usar
* com animações suaves
* microinterações modernas
* navegação fluida

6. TECNOLOGIAS SUGERIDAS
   Frontend:

* React / Next.js
* TailwindCSS
* Framer Motion
* Charts modernos

Backend:

* Node.js
* API modular
* arquitetura escalável
* autenticação JWT

Banco:

* PostgreSQL ou MySQL

7. ESTRUTURA VISUAL
   Criar telas para:

* Login
* Dashboard
* Estoque
* Produtos
* Usuários
* Relatórios
* Configurações

8. ESTILO VISUAL DAS TELAS
   Desejo:

* sidebar moderna
* ícones minimalistas
* cards sofisticados
* gráficos futuristas
* tabelas elegantes
* sombras suaves
* contraste premium
* design semelhante a plataformas SaaS modernas

9. DIFERENCIAIS
   Adicionar:

* alertas automáticos de estoque baixo
* sistema de notificações
* atividade recente
* histórico de movimentações
* status visual dos produtos
* indicadores coloridos
* badges modernos

10. DIREÇÃO CRIATIVA
    O sistema deve transmitir:

* inovação
* organização
* velocidade
* confiabilidade
* tecnologia
* sofisticação

A estética deve combinar:

* moda urbana
* tecnologia
* gestão empresarial moderna
